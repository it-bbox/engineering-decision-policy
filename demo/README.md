# Демонстрация: экспорт строк

`export_rows(rows, emit, formatter=str)` принимает список строк, возвращает tuple
и отправляет те же строки в sink. Контракт примера требует детерминированный
formatter без побочных эффектов; все данные тестов — списки, не генераторы.
Политика проверяет подстановку sink, расширение formatter и два клиента.

В baseline есть лишний вывод в stdout. Testable убирает его. Compact-regression
сокращает строки, возвращая побочный вывод. Efficient форматирует строки один раз
вместо двух. Последний приём корректен только при указанном контракте formatter;
для stateful-formatter такое изменение потребовало бы другого контракта и тестов.

```sh
python3 scripts/run_demo.py
```

Скрипт реально импортирует каждый модуль, запускает сценарии, считает AST-узлы,
строки и вызовы. Затем вызывает evaluate для пар и проверяет ожидаемые статусы:

| Пара | Цель | Результат |
|---|---|---|
| baseline → testable | testability | ACCEPT |
| testable → compact-regression | source_lines | REJECT: регрессия testability |
| testable → efficient | formatter_calls | ACCEPT |
| testable → unknown-hard | testability | INCONCLUSIVE |

Первые три пары основаны на выполненном коде. Unknown-hard — намеренно изменённая
копия отчёта для демонстрации отсутствующего доказательства; она не выдаётся за
новый прогон кода. Измерение времени здесь не выполняется: число вызовов — лишь
прокси производительности. Условия и пороги demo не переносятся на произвольный
проект автоматически. Отчёты переиздаются с текущей датой и средой при запуске.
