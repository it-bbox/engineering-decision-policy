# Проверка комплекта v2

Проверено 2 ноября 2026 года. Это отчёт о механизме и артефактах этого комплекта;
эмпирическая эффективность политики на реальных задачах здесь не установлена.

- 25 unit-тестов сравнителя: ранние регрессии, hard constraints, unknown,
  недостигнутые пороги, некорректные типы, несопоставимые отчёты и порядок профиля.
- Запускаемый demo: четыре ожидаемых решения проверены для каждого из трёх профилей.
- Прямой запуск CLI: проверены JSON-результаты и коды возврата ACCEPT/REJECT.
- Формат SKILL.md: проверен штатным валидатором навыков.
- HTML: проверен в установленном Google Chrome на macOS при ширинах 320, 375,
  768, 1024 и 1440 px. Горизонтальное переполнение отсутствует.
- Веб-модель: четыре сценария, смена профиля, численный hard limit и unknown
  раннего уровня дают ожидаемые решения. Ошибок JavaScript не обнаружено.
- Просмотрщик: встроенный текст каждого исходного файла сопоставлен с файлом
  комплекта; скачанный SKILL.md совпадает с исходником.
- Автономность: при открытии HTML с диска не было сетевых запросов; все стили,
  код модели и тексты исходников встроены. Внешние ссылки используются по нажатию.
- ZIP: проверяется распаковка и контрольные суммы содержимого в SHA256SUMS.txt.
- Публичные материалы проверены на отсутствие личных адресов, локальных путей
  и упоминаний частных обсуждений.

Ограничения: отдельный прогон в Firefox/Safari, проверка скринридером и аудит
доступности не выполнялись. Подпись отчётов и достоверность внешних адаптеров
не проверяются сравнителем. При подключении реального проекта нужна его
собственная система измерений и отдельная валидация.
